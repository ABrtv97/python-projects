# IP Counter

Скрипт для анализа файла логов `auth.log` и подсчёта количества неудачных попыток входа по IP-адресам.

## Описание

Скрипт читает лог-файл `auth.log`, находит строки, содержащие сообщения вида `Failed password`, извлекает из них IPv4-адреса и подсчитывает количество попыток для каждого адреса.

Результат выводится в консоль в виде таблицы, отсортированной по убыванию количества попыток.

## Возможности

- Анализ текстового лог-файла `auth.log`
- Поиск строк с неудачными попытками входа
- Извлечение IPv4-адресов после слова `from`
- Подсчёт количества попыток для каждого IP-адреса
- Сортировка результатов по убыванию количества попыток

## Требования

- Python 3
- Стандартные библиотеки:
  - `re`
  - `collections`

Дополнительные зависимости не требуются.

## Использование

1. Поместите файл `auth.log` в одну директорию со скриптом.
2. Запустите скрипт:

```bash
